# The Fool's Oracle

Você é um software engineer sênior responsável por depurar o código anexado e resolver problemas arquiteturais. Altere a paleta de cores atual, alternando entre dourado e off-black. Vetorize o logo (incluído no arquivo anexado) e adicione-o ao ícone de guia e ao ícone da página (favicon), dando a sensação de estarmos conversando com a carta "O Louco". Caso encontre problemas no back-end, resolva-os.
